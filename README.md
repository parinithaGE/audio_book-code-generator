# Simple Repository Feature Agent

Fixed repository: https://github.com/Python-World/python-mini-projects
Fixed target: projects/AudioBook/Audio-book.py

Workflow: GitHub MCP read -> generate -> 3 evaluation passes -> test with supplied PDF.

Run:
1. Copy `.env.example` to `.env` and fill values.
2. `pip install -r requirements.txt`
3. Put a PDF in the project folder or upload it in the UI.
4. `streamlit run app.py`
